# Clock-project

This project references jnthas' clockwise.
Github link: https://github.com/jnthas/clockwise

## Functions

1.Switching the clock display
Turn the knob to change the different clock displays.

2.Adjusting the brightness of the Matrix Panel
Slide the screen left and adjust the knob to adjust the brightness.

3.Automatically turning off the screen
Automatically switch off the screen after 30s without operation, and can be woken up by touching the screen.
